# Backend — ConectaUnB

API NestJS do ConectaUnB.

## Scripts

```bash
pnpm --filter back dev          # Desenvolvimento com watch
pnpm --filter back build        # Compilar
pnpm --filter back test         # Testes unitários
pnpm --filter back test:e2e     # Testes e2e
pnpm --filter back prisma:studio # Abrir Prisma Studio
```
