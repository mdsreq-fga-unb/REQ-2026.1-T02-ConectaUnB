## Regras de negócio
- [ ] **RN1:** O sistema deve filtrar os processos seletivos abertos quando o usuário aplicar um ou mais parâmetros de categorização na busca, exibindo apenas as categorias selecionadas.

## Tarefas
**Frontend**
- [ ] Adicionar componente de filtros (por categorias/tags) na página de listagem de processos seletivos.
- [ ] Integrar aplicação dos filtros com os parâmetros da requisição para a API.
- [ ] Garantir atualização dinâmica e feedback visual ao aplicar os filtros.

**Backend**
- [ ] Atualizar a rota GET do Modulo Processo Seletivo para receber e processar os parâmetros de busca/filtragem.
- [ ] Implementar a lógica de filtro no banco de dados.
- [ ] Criação de testes Unitários para a filtragem de Processos Seletivos.
