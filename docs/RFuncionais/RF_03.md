## Regras de negócio
- [ ] **RN1:** O sistema deve atualizar o status de um processo seletivo apenas para usuários com privilégios de gestor.
- [ ] **RN2:** O usuário deverá escolher classificações de status pré definidas (aberto, finalizado, etc.).

## Tarefas
**Frontend**
- [ ] Criar componente de seleção/dropdown para alteração de status no painel de gestão.
- [ ] Restringir as opções disponíveis às classificações de status pré-definidas.
- [ ] Integrar ação de mudança de status com a API e implementar feedback visual (sucesso ou erro).

**Backend**
- [ ] Atualizar rotas do Modulo Processo Seletivo (Criar/revisar rota PATCH/PUT de atualização).
- [ ] Implementar validação para garantir que apenas gestores possam executar a ação.
- [ ] Criação de testes Unitários para atualização de status de Processos Seletivos.
