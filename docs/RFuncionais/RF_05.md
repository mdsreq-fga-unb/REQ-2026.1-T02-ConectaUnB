# RF-05: Permitir a criação de processo seletivo delimitando data limite

## Descrição
Permitir a criação de processo seletivo delimitando data limite.

## Rastreabilidade

- **RNFs Relacionados:**

**[RNF-04](https://miro.com/app/board/uXjVHTrU614=/?openCardPanel=3458764676223010040)** - Feedback responsivo

Discutido na [fase 1 entrevista 1](../userDesign/Fase1/analiseEntrevista24-04.md)

## Regras de negócio
- [ ] **RN1:** O sistema deve criar um processo seletivo quando o gestor da entidade submeter o formulário preenchido corretamente.
- [ ] **RN2:** É necessário delimitar uma data de término de inscrição válida.

![Image](../assets/fotos_prototipos/projetos.png)

## Tarefas
**Frontend**
- [ ] Criação do Componente/Página de Cadastro de Processo Seletivo.
- [ ] Adicionar formulário de criação com validação do campo obrigatório de data limite (término da inscrição).
- [ ] Integrar a submissão do formulário com a API.
- [ ] Implementar feedback visual (sucesso na criação ou apontamento de erros).

**Backend**
- [ ] Atualizar rotas do Modulo Processo Seletivo (Criar rota POST utilizando o `CreateProcessoSeletivoDto`).
- [ ] Validar os dados recebidos, especialmente o formato e a coerência das datas de início e fim da inscrição.
- [ ] Criação de testes Unitários para a criação de Processos Seletivos.
