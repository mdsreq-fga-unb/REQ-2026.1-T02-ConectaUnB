## Regras de negócio
- [x] **RN1:** A edição do perfil da entidade só será considerada concluída quando o usuário salvar as alterações realizadas, o banco de dados der um feedback, o usuário receberá a mensagem “Edição concluída com sucesso” na tela e for redirecionado para a página de perfil com as informações atualizadas.
- [x] **RN2:** Caso haja falha na edição o usuário deve ser avisado como prosseguir.

## Tarefas
**Frontend**
- [x] Criação da Página/Componente de Edição do Perfil de Entidade.
- [x] Criação de modal de edição do perfil de entidade.
  - nome
  - classificação
  - campus
  - departamento
  - descrição
  - foto banner
  - foto logo
- [x] Integrar formulário com os dados atuais e rota de atualização da API.
- [x] Implementar feedback visual e redirecionamento de tela em caso de sucesso ou erro.

**Backend**
- [x] Atualizar rotas do Modulo Entidade (Criar rota PATCH/PUT para atualização de dados).
- [x] Validar permissões de edição no backend (apenas gestores ou coordenadores).
- [x] Criação de testes Unitários para Edição de Perfil Entidade.
