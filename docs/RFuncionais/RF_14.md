# RF-14: Permitir a exclusão dos dados de um perfil de entidade

## Descrição
O sistema deve permitir a exclusão dos dados de um perfil de entidade.

## Regras de negócio
- [x] **RN1:** A exclusão do perfil da entidade só será considerada concluída quando o usuário confirmar a ação de exclusão, receber a mensagem “Conta excluída com sucesso” na tela.
- [ ] **RN2:** O perfil só será considerado excluído quando todas as suas evidências forem removidas do banco de dados, incluindo mas não se limitando a posts, e projetos, etc.

## Tarefas
**Frontend**
- [x] Adicionar componente de modal para confirmação de exclusão da entidade.
- [x] Integrar confirmação de exclusão com a API (rota DELETE).
- [x] Exibir mensagem de sucesso e realizar o redirecionamento adequado.

**Backend**
- [x] Atualizar rotas do Modulo Entidade (Criar rota DELETE).
- [ ] Implementar lógica de exclusão em cascata para remover evidências associadas (posts, projetos, etc.).
