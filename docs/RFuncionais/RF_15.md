# RF-15: Permitir a visualização dos dados de um perfil de entidade

## Descrição
O sistema deve permitir a visualização dos dados de um perfil de entidade.

## Rastreabilidade

- **RNFs Relacionados:**

**[RNF-01](https://miro.com/app/board/uXjVHTrU614=/?openCardPanel=3458764676223668243)** - Acessar plataforma sem login

Discutido na [fase 1 entrevista 2](../userDesign/Fase1/analiseEntrevista29-04.md)

## Regras de negócio
- [ ] **RN1:** O acesso ao perfil da entidade só será considerado concluído quando o usuário for redirecionado para a visualização da entidade e conseguir visualizar corretamente as informações cadastradas, incluindo nome, nome de usuário, foto, publicações e número de seguidores.

## Tarefas
**Frontend**
- [ ] Criação da Página Pública de Perfil da Entidade.
- [ ] Integrar a visualização consumindo os dados públicos da API (nome, foto, métricas e publicações).
- [ ] Configurar o roteamento dinâmico para acesso à página da entidade.

**Backend**
- [ ] Atualizar rotas do Modulo Entidade (Criar/revisar rota GET pública para buscar informações da entidade).
- [ ] Criação de testes Unitários para Visualização de Perfil Entidade.
