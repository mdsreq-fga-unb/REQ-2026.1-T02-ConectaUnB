## Regras de negócio
- [x] **RN1:** A edição do perfil de usuário só será considerada concluída quando o usuário salvar as alterações realizadas.
- [x] **RN2:** O usuário deve receber a mensagem “Edição concluída com sucesso” na tela após concluir a edição e salvar as alterações.
- [x] **RN3:** O usuário deve visualizar as informações atualizadas em sua página de perfil.
- [ ] **RN4:** O usuário deve ser capaz de alterar foto de perfil/foto do banner/nome/descrição/campus.
