# RF-19: Permitir a exclusão dos dados de um perfil de usuário

## Descrição
O sistema deve permitir a exclusão dos dados de um perfil de usuário.

## Rastreabilidade

- **RNFs Relacionados:**

**[RNF-03](../RNAOFuncionais/RNF_03.md)** - Manter consistência visual

**[RNF-04](../RNAOFuncionais/RNF_04.md)** - Feedback responsivo

Discutido na [fase 1 entrevista 2](../userDesign/Fase1/analiseEntrevista29-04.md)

## Regras de negócio
- [x] **RN1:** A exclusão só será considerada concluída quando o usuário confirmar a ação, receber a mensagem "Conta excluída com sucesso".
- [x] **RN2:** O usuário deve ser redirecionado para a página inicial no formato deslogado ao excluir seu perfil.
- [x] **RN3:** O perfil só será considerado excluído quando nenhum dado identificável do usuário puder ser acessado por outros usuários do sistema.
- [ ] **RN4:** A exclusão de um perfil não deve afetar as métricas de engajamento já registradas pelo sistema.
