# RF-26: Permitir criar posts contendo texto e imagem

## Regras de negócio
- [ ] **RN1:** Uma publicação pode ser criada contendo apenas texto ou apenas imagem ou ambos.
- [ ] **RN2:** Usuários devem poder ver como ficará o post antes de publicá-lo (preview).
- [ ] **RN3:** Após a publicação o post deve aparecer nos publicações do perfil da entidade.

## Tarefas
**Frontend**
- [ ] Criação do Componente/Modal de criação de postagem.
  - id entidade
  - título
  - conteúdo
  - link foto
- [ ] Adicionar formulário de criação com suporte à inserção de texto e upload de imagem.
- [ ] Implementar a funcionalidade de visualização prévia (preview) antes da submissão.
- [ ] Integrar o formulário de criação de post com a API.

**Backend**
- [ ] Atualizar rotas do Modulo Postagem (Criar rota POST para criação de postagem).
- [ ] Validar no backend o recebimento de texto, imagem ou ambos.
- [ ] Criação de testes Unitários para Criação de Publicações.
