# RF-26: Permitir criar posts contendo texto e imagem

## Descrição
O sistema deve permitir criar posts contendo texto e imagem, podendo ser apenas um dos dois

## Rastreabilidade

- **RNFs Relacionados:**

**[RNF-04](../RNAOFuncionais/RNF_04.md)** - Feedback responsivo

Discutido na [fase 1 entrevista 1](../userDesign/Fase1/analiseEntrevista24-04.md)

## Regras de negócio
- [ ] **RN1:** Uma publicação pode ser criada contendo apenas texto ou apenas imagem ou ambos.
- [ ] **RN2:** Usuários devem poder ver como ficará o post antes de publicá-lo (preview).
- [x] **RN3:** Após a publicação o post deve aparecer nos publicações do perfil da entidade.
