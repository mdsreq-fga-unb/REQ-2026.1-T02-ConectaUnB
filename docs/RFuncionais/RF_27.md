## Regras de negócio
- [ ] **RN1:** A edição deve permitir editar todos os campos de um post.
- [ ] **RN2:** Usuário deve conseguir ver como ficará o post antes de concluir a edição.

## Tarefas
**Frontend**
- [ ] Criação do Componente/Modal de edição de postagem.
- [ ] Preencher formulário de edição com os dados originais da publicação.
- [ ] Implementar a funcionalidade de visualização prévia (preview) da edição.
- [ ] Integrar a submissão das alterações com a API.

**Backend**
- [ ] Atualizar rotas do Modulo Postagem (Criar/revisar rota PATCH/PUT para atualização da publicação).
- [ ] Validar permissões de edição para garantir que apenas usuários autorizados editem o post.
- [ ] Criação de testes Unitários para Edição de Publicações.
