## Regras de negócio

## Tarefas
**Frontend**
- [ ] Adicionar componente de modal para confirmação da exclusão do post.
- [ ] Integrar a ação de confirmação de exclusão com a API (rota DELETE).
- [ ] Atualizar a interface removendo dinamicamente a publicação excluída do feed ou perfil.

**Backend**
- [ ] Atualizar rotas do Modulo Postagem (Criar/revisar rota DELETE).
- [ ] Implementar a lógica de exclusão no banco de dados garantindo a remoção de todas as evidências (textos, imagens, etc.).
- [ ] Criação de testes Unitários para Exclusão de Publicações.
