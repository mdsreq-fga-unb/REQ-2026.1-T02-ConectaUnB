# RF-06: Filtrar feed em relação a capums/área de interesse/tipo da entidade

## Descrição
O sistema deve permitir a configuração de filtros de interesses pessoais (ex: equipes de competição, PIBIC) para personalizar o feed de visualização.

## Regras de negócio
- [ ] **RN1:** O sistema deve filtrar as publicações do feed quando o usuário autenticado tiver filtros de interesses pessoais configurados, restringindo a exibição exclusivamente às postagens que possuam as tags ou categorias correspondentes às suas preferências.
- [ ] **RN2:** Os filtros disponíveis devem refletir apenas as características presentes no banco de dados (se não houver uma instituição EJ no banco então esse filtro não deve estar disponível).
