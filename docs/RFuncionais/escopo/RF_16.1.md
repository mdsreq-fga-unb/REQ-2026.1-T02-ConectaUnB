# RF-16.1: Adicionar Co-gestores das entidades

## Descrição
O sistema deve permitir a adição de usuários (docentes ou discentes) como co-gestores de uma entidade quando a ação for realizada por um usuário que já possua privilégios de gestor nela.

## Rastreabilidade

- **RNFs Relacionados:** 
[RNF04](../../RNAOFuncionais/RNF_04.md) - Feedback responsivo

Discutido na [fase 1 entrevista 2](../userDesign/Fase1/analiseEntrevista29-04.md)
## Regras de negócio
- [ ] **RN1:** O gerenciamento de co-gestores só será considerado concluído quando o administrador da entidade conseguir adicionar co-gestores do perfil da entidade.
- [ ] **RN2:** O usuario administrador deve conseguir visualizar a lista atualizada de co-gestores após a alteração.
- [ ] **RN3:** O usuario administrador deve receber uma mensagem de confirmação da ação realizada na tela (Ex: "Co-gestor adicionado com sucesso").

## DoR
- [ ] O escopo e a regra de negócio estão claros e sem ambiguidades.
- [ ] Protótipos aprovados pelos clientes.
