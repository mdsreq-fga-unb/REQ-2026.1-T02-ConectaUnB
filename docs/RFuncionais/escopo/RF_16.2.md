# RF-16.2: Remover Co-gestores das entidades

## Descrição
O sistema deve permitir a remoção de usuários (docentes ou discentes) como co-gestores de uma entidade quando a ação for realizada por um usuário que já possua privilégios de gestor nela.

## Regras de negócio
- [ ] **RN1:** O gerenciamento de co-gestores só será considerado concluído quando o administrador da entidade conseguir remover co-gestores do perfil da entidade.
- [ ] **RN2:** O usuario administrador deve conseguir visualizar a lista atualizada de co-gestores após a alteração.
- [ ] **RN3:** O usuario administrador deve receber uma mensagem de confirmação da ação realizada na tela (Ex: "Co-gestor removido com sucesso").
