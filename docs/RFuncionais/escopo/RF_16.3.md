# RF-16.3: Visualizar Co-gestores das entidades

## Descrição
O sistema deve permitir a visualização dos usuários (docentes ou discentes) co-gestores de uma entidade quando a ação for realizada por um usuário que já possua privilégios de gestor ou co-gestor nela.

## Regras de negócio
- [ ] **RN1:** A visualização de co-gestores só será considerado concluída quando o administrador da entidade conseguir ver todos os participantes do perfil da entidade.
- [ ] **RN2:** A visualização também deve permitir adicionar ou remover usuários co-gestores.
