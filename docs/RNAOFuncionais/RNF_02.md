# RNF-02: Facilidade no uso

### Usabilidade

## Descrição
O sistema deve ter uma interface simples, permitindo que qualquer funcionalidade principal seja alcançada em no máximo 6 cliques.

## Rastreabilidade

Discutido na [fase 1 entrevista 3](../userDesign/Fase1/analiseEntrevista30-04.md)

## Regras de negócio
- [x] **RN1:** O usuário deve conseguir concluir os fluxos principais do sistema em até 6 cliques.
- [x] **RN2:** Os fluxos essenciais devem ser validados por testes para garantir que nenhuma funcionalidade importante exija 7 cliques ou mais.
