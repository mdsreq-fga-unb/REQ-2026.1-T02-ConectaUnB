# RNF-03: Manter consistência visual

### Usabilidade

## Descrição
O sistema deve manter consistência visual, com a mesma paleta de cores, tipografia e componentes em todas as partes da aplicação.

## Rastreabilidade

Discutido na [fase 1 entrevista 3](../userDesign/Fase1/analiseEntrevista30-04.md)

## Regras de negócio
- [x] **RN1:** O sistema deve usar o mesmo padrão visual em toda a aplicação.
- [x] **RN2:** Componentes iguais devem manter o mesmo comportamento, aparência e funcionamento em todos os perfis de acesso.
