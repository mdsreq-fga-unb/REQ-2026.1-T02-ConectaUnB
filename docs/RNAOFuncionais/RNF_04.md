# RNF-04: Feedback responsivo

### Usabilidade

## Descrição
O sistema deve possuir interface responsiva, sempre comunicando com o usuário se o processamento foi concluído ou não, se houve algum erro e como o usuário pode corrigir.

## Regras de negócio
