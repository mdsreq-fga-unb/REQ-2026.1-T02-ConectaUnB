# RNF-05: Uso mobile e desktop

### Suportabilidade

## Descrição
O sistema deve ser funcional em desktops e mobile (através do navegador).

## Rastreabilidade

requisito implícito

## Regras de negócio
- [x] **RN1:** A aplicação deve se adequar ao tamanho de tela médio de um desktop (14 polegadas)
- [x] **RN2:** A aplicação deve se adequar ao tamanho de tela médio de um celular (6,2 polegadas)
